How to Download Pinterest Videos on PC and Mac

Tutorial Published: November 2026 5 min read By Manikant Yadav

On a computer, saving a Pinterest video is easier than on a phone. There's no "move it to the gallery" step, and the file lands in a folder you already know. The only part that varies is the browser: where it puts the file, and what it does when a video opens in a tab instead of downloading. Both are covered below for Windows and Mac.

The three steps

1

Copy the pin's address

Open the video pin on pinterest.com so it fills the page, then click the address bar and copy the URL with Ctrl + C (Cmd + C on a Mac). It should contain /pin/ followed by a number. If you're on the home feed, click the video first; the feed's address isn't a pin link.

2

Paste it into KlickPint

Open klickpint.online in a second tab, click the input box, press Ctrl + V (Cmd + V) and then Enter. You'll see a preview and the qualities Pinterest has for that pin.

3

Click a quality

On a laptop or monitor, 1080p is worth it when it's offered. A progress bar fills in, and the MP4 is saved as soon as it finishes.

Where the file goes

Every browser saves to your Downloads folder unless you've changed it. Here is how to jump straight to the file:

BrowserOpen the downloads listDefault folder
Chrome (Windows)Ctrl + J, or the download icon in the toolbarC:\Users\you\Downloads
Edge (Windows)Ctrl + JC:\Users\you\Downloads
Firefox (Windows)Ctrl + Shift + Y, or the arrow in the toolbarC:\Users\you\Downloads
Safari (Mac)Option + Cmd + L, or the arrow in the toolbarDownloads in the Dock / Finder
Chrome or Firefox (Mac)The download icon in the toolbarDownloads in Finder

In any of these lists, the small folder or magnifying-glass icon next to the file opens it in File Explorer or Finder. The file is named something like klickpint-recipe-video-1080p.mp4, so it's easy to spot.

If the video opens in a tab instead of downloading

Sometimes the browser decides to play the video rather than save it, usually when a browser extension or a strict privacy setting gets in the way of the normal download. You'll see a black page with a video player. It's the right file, it just hasn't been saved yet:

  • Right-click the video and choose Save video as… (Chrome, Edge, Firefox) or Download Video (Safari).
  • Or press Ctrl + S (Cmd + S) while the video tab is open.

If it happens every time, try the same pin with extensions turned off (a private window usually does that), or in a different browser. Our troubleshooting guide covers the other common causes.

Choose where downloads are saved

If you save a lot of Pinterest videos for a project, it's handy to send them to their own folder. Every browser can ask you each time:

  • Chrome: Settings → Downloads → turn on Ask where to save each file before downloading.
  • Edge: Settings → Downloads → turn on Ask me what to do with each download.
  • Firefox: Settings → General → Files and Applications → choose Always ask you where to save files.
  • Safari: Settings → General → File download location → Ask for each download.

Playing the MP4

Double-click it. On Windows 11 it opens in Media Player, on older Windows in Films & TV, and on a Mac in QuickTime Player. All of them play Pinterest videos. If a file won't play or has no sound, VLC is a free player that handles almost anything, and our guide on Pinterest videos with no sound explains the usual reasons for silence.

Frequently asked questions

Do I need to install a program or browser extension?

No. KlickPint works in the browser you already have. Be careful with "Pinterest downloader" extensions in general: an extension can read every page you visit, which is a lot of access for saving a video.

Can I save images and GIFs the same way?

Yes. Paste an image pin and you get the original file instead of the small copy that "Save image as" gives you. See the image downloader and the GIF downloader.

Can I use a download manager?

Yes. After you paste a link, each quality has a small copy icon next to it that copies the direct file link. Paste that into your download manager.

Does it work on Linux or a Chromebook?

Yes. Any modern browser works. On a Chromebook the file goes to Downloads in the Files app.

Remember: Save videos for your own use. Reposting someone's video or using it to make money needs their permission. If you want to ask, our guide on finding a pin's original creator shows how to track them down.
